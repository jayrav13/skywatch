# Mayday Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the Mayday domain — a one-shot, scoped query that returns aircraft squawking 7500/7600/7700 within N nm of a point, classified and ready for an agent to consume.

**Architecture:** Thin composition layer over the existing Radar/OpenSky source. New `Mayday::Models::Emergency` wraps a `Radar::Models::StateVector` and exposes `emergency_type` + `label`. New `Mayday::Sources::Emergency#near(lat:, lon:, radius_nm:)` reuses `Radar::Analysis::Proximity.bbox`, `Radar::Sources::Opensky#states_bbox`, and `Radar::Analysis::Proximity.within_radius`, then filters via the already-existing `StateVector#emergency?` predicate. New formatter and Thor CLI subcommand follow the existing per-domain patterns. Top-level `Skywatch.mayday(...)` is a one-line convenience.

**Tech Stack:** Ruby, Thor (CLI), RSpec + WebMock (tests), Faraday via the shared HTTP client (no new HTTP plumbing).

**Spec:** `docs/superpowers/specs/2026-04-18-mayday-design.md`.

## Task 2: `Mayday::Models::Emergency`

**Files:**
- Create: `lib/skywatch/mayday/models/emergency.rb`

### Behavior

- Initializer takes one positional arg: a `Radar::Models::StateVector`.
- Raises `ArgumentError` if the vector's squawk is not one of `"7500"`, `"7600"`, `"7700"`.
- Exposes `squawk`, `emergency_type` (Symbol), `label` (String), and the underlying `state_vector` (developer escape hatch).
- Delegates `callsign`, `icao24`, `latitude`, `longitude`, `altitude_ft`, `velocity_kt`, `on_ground` to the wrapped state vector.
- `heading_deg` returns the wrapped vector's `true_track_deg` (renamed for ergonomics).
- `to_h` returns the dictionary spelled out in the spec.
- `to_json(*)` serializes via `to_h`.

# frozen_string_literal: true

require 'forwardable'
require 'json'

module Skywatch
  module Mayday
    module Models
      class Emergency
        extend Forwardable

        TYPES = {
          '7500' => { type: :hijack,         label: 'HIJACK' },
          '7600' => { type: :radio_failure,  label: 'RADIO FAILURE' },
          '7700' => { type: :general,        label: 'GENERAL EMERGENCY' }
        }.freeze

        attr_reader :state_vector

        def_delegators :@state_vector,
                       :callsign, :icao24, :latitude, :longitude,
                       :altitude_ft, :velocity_kt, :on_ground

        def initialize(state_vector)
          unless TYPES.key?(state_vector.squawk)
            raise ArgumentError, "Not an emergency squawk: #{state_vector.squawk.inspect}"
          end

          @state_vector = state_vector
        end

        def squawk
          state_vector.squawk
        end

        def emergency_type
          TYPES.fetch(squawk)[:type]
        end

        def label
          TYPES.fetch(squawk)[:label]
        end

        def heading_deg
          state_vector.true_track_deg
        end

        def to_h
          {
            callsign: callsign, icao24: icao24, squawk: squawk,
            emergency_type: emergency_type, label: label,
            latitude: latitude, longitude: longitude,
            altitude_ft: altitude_ft, velocity_kt: velocity_kt, heading_deg: heading_deg,
            on_ground: on_ground
          }
        end

        def to_json(*args)
          to_h.to_json(*args)
        end
      end
    end
  end
end
```

### Behavior

- `near(lat:, lon:, radius_nm: 100)` returns an Array of `Mayday::Models::Emergency`.
- Composition: `Proximity.bbox` → `Opensky.states_bbox` → `Proximity.within_radius` → `select(&:emergency?)` → wrap in `Emergency`.
- No filtering of normal aircraft happens before `select(&:emergency?)`; relying on the existing predicate keeps Mayday from drifting if Radar's definition of "emergency" ever changes.
- The OpenSky source is constructed inline (it owns its own cached HTTP client, like the existing radar convenience methods do).

# frozen_string_literal: true

module Skywatch
  module Mayday
    module Sources
      class Emergency
        DEFAULT_RADIUS_NM = 100

        def initialize(opensky: Skywatch::Radar::Sources::Opensky.new)
          @opensky = opensky
        end

        def near(lat:, lon:, radius_nm: DEFAULT_RADIUS_NM)
          bbox = Skywatch::Radar::Analysis::Proximity.bbox(lat, lon, radius_nm: radius_nm)
          vectors = @opensky.states_bbox(**bbox)
          in_radius = Skywatch::Radar::Analysis::Proximity.within_radius(
            vectors, lat: lat, lon: lon, radius_nm: radius_nm
          )
          in_radius.select(&:emergency?).map { |sv| Models::Emergency.new(sv) }
        end
      end
    end
  end
end
```

(The `opensky:` initializer keyword exists for testability, but the spec above does not need to inject it — the WebMock stub catches the real OpenSky URL.)

### Output format

```
MAYDAY: GENERAL EMERGENCY (squawk 7700)
  Callsign: GEN0004   ICAO24: a00004
  Position: 41.0000, -74.0000   Alt: FL320   Spd: 389kt   Hdg: 090°
```

- Altitude rendered as `FL###` rounded to nearest 100ft (matches the SIGMET formatter's flight-level convention). If `altitude_ft` is nil, render `Alt: ---`.
- Heading rendered as 3-digit zero-padded degrees. If nil, render `Hdg: ---`.
- Speed rendered as integer kt. If nil, render `Spd: ---`.
- Position rendered to 4 decimals.

# frozen_string_literal: true

module Skywatch
  module Mayday
    module Formatters
      module Text
        def self.format_emergency(emergency) # rubocop:disable Metrics/AbcSize
          alt = format_altitude(emergency.altitude_ft)
          spd = emergency.velocity_kt ? "#{emergency.velocity_kt}kt" : '---'
          hdg = format_heading(emergency.heading_deg)
          pos = format_position(emergency.latitude, emergency.longitude)

          <<~TEXT
            MAYDAY: #{emergency.label} (squawk #{emergency.squawk})
              Callsign: #{emergency.callsign || '---'}   ICAO24: #{emergency.icao24}
              Position: #{pos}   Alt: #{alt}   Spd: #{spd}   Hdg: #{hdg}
          TEXT
        end

        def self.format_altitude(altitude_ft)
          return '---' if altitude_ft.nil?

          format('FL%03d', (altitude_ft / 100.0).round)
        end

        def self.format_heading(heading_deg)
          return '---' if heading_deg.nil?

          format('%03d°', heading_deg.round)
        end

        def self.format_position(lat, lon)
          return '---' if lat.nil? || lon.nil?

          format('%.4f, %.4f', lat, lon)
        end

        private_class_method :format_altitude, :format_heading, :format_position
      end
    end
  end
end
```

### Behavior

- `skywatch mayday near LAT LON [--radius N] [--format text|json]`
- Default `--radius` is 100 (matches the convenience API and the spec).
- Output format follows the project convention: explicit `--format` wins; otherwise text on TTY, JSON when piped.
- Empty result:
  - text → `No emergencies within Nnm of LAT, LON`
  - JSON → `[]`
- Errors → `warn "Error: #{e.message}"` + `exit 1` (matches `Skywatch::Radar::CLI`).

# frozen_string_literal: true

require 'thor'
require 'json'

module Skywatch
  module Mayday
    class CLI < Thor
      class_option :format, type: :string, enum: %w[text json],
                            desc: 'Output format (default: text on TTY, json when piped)'

      desc 'near LAT LON', 'Aircraft squawking emergency (7500/7600/7700) within radius'
      option :radius, type: :numeric, default: 100, desc: 'Search radius in NM'
      def near(lat, lon) # rubocop:disable Metrics/AbcSize, Metrics/MethodLength
        emergencies = Skywatch.mayday(lat: lat.to_f, lon: lon.to_f, radius_nm: options[:radius])

        if output_format == 'json'
          puts JSON.pretty_generate(emergencies.map(&:to_h))
        elsif emergencies.empty?
          puts "No emergencies within #{options[:radius]}nm of #{lat}, #{lon}"
        else
          emergencies.each { |e| print Skywatch::Mayday::Formatters::Text.format_emergency(e) }
        end
      rescue Skywatch::Error => e
        warn "Error: #{e.message}"
        exit 1
      end

      private

      def output_format
        options[:format] || ($stdout.tty? ? 'text' : 'json')
      end
    end
  end
end
```

Note: `JSON.pretty_generate([])` produces `"[]"` with no newline before it, which matches the test's `expect(output.strip).to eq('[]')`.
